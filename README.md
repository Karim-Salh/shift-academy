# SHIFT Academy

موقع ثابت جاهز: ملفات HTML فقط بدون تثبيت أو خادم.

## التشغيل محليًا
افتح `index.html` بالضغط المزدوج.

## الرفع على GitHub
ارفع محتوى المجلد كما هو على مستودع GitHub، ثم من Settings > Pages اختر الفرع `main` والمجلد `/ (root)`. يعمل على `https://USERNAME.github.io/REPO/`.

## الإدارة والحفظ التلقائي
رابط "الإدارة" في آخر الموقع، وكلمة المرور الأولية `192005k` (غيّرها من تبويب "الأمان").
لتصبح كل التعديلات والصور تُنشر تلقائيًا للزوار، اربط الإدارة بالمستودع **مرة واحدة** من تبويب "الربط" (الخطوات مكتوبة هناك): تنشئ Token بصلاحية Contents: Read and write لمستودع الموقع فقط وتلصقه. بعدها أي تعديل يُحفظ وينشر لوحده ويظهر في الموقع خلال دقيقة تقريبًا.
الـ Token يُحفظ في متصفحك فقط، ولا تضعه في أي ملف داخل المشروع ولا تشاركه.
قفل الإدارة يعمل داخل المتصفح، والحماية الفعلية لأي تعديل هي الـ Token.
